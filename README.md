# Djembe Rhythm Game

HTML5 Canvas and Web Audio based djembe rhythm trainer.

## Run Locally

Use any local static server from the repository root.

```bash
python -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```

## Controls

- `D`: Slap
- `Space`: Bass
- `K`: Tone
- Touch left / center / right thirds on mobile

## Deploy

GitHub Pages is deployed by `.github/workflows/deploy-pages.yml`.
